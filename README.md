# IELTS Foundation Notes

Mở `index.html` bằng Chrome hoặc Edge.

Định hướng hiện tại:
- Web dạng note học tập, ít nút bấm.
- Current Stage ghi rõ mục tiêu giai đoạn hiện tại và phạm vi đã học đến Lesson 15.
- Course Map theo Lesson 1–15, chỉ dùng làm bản đồ nguồn kiến thức.
- Grammar Notes: khái niệm, công thức, cách dùng, dấu hiệu, ví dụ, bẫy lỗi.
- Speaking Notes giữ nguyên ví dụ thật trong source và thêm gợi ý ngắt hơi/từ cần nhấn.
- Audio Speaking từ trung tâm được nhúng trong `Speaking Notes` nếu có file trong thư mục `audio/`.
- Pronunciation Notes: IPA cơ bản, trọng âm, âm cuối, -s/-es, -ed.
- Review Up To Lesson 15: ôn theo chủ đề, lỗi thường sai, homework/review và vocabulary bank.
- Chạy offline trong một file `index.html`.
- Source học liệu nằm trong thư mục `source/`, gộp theo chủ điểm chính trong lộ trình học:
- `01-Grammar-Foundation.md`
- `02-Grammar-Present-Tenses.md`
- `03-Grammar-Past-Tenses.md`
- `04-Grammar-Future-Tenses.md`
- `05-Speaking-Topics.md`
- `06-Grammar-Modal-Verbs.md`
